5 JavaScript array methods

map, filter, reduce, find and some in one place.

JavaScript 
const numbers = [1, 2, 3, 4, 5];

const doubled = numbers.map(n => n * 2);
const evens = numbers.filter(n => n % 2 === 0);
const total = numbers.reduce((sum, n) => sum + n, 0);
const firstBig = numbers.find(n => n > 3);
const hasNegative = numbers.some(n => n < 0);

console.log(doubled, evens, total, firstBig, hasNegative);

5 ways to load your website faster

Small HTML changes that speed up a page.

HTML 
<!-- lazy-load images below the fold, and set a size -->
<img src="photo.jpg" alt="Describe the photo" loading="lazy" width="800" height="450">

<!-- load JavaScript without blocking the page -->
<script src="script.js" defer></script>

<!-- load important CSS early -->
<link rel="preload" href="style.css" as="style">
